# Знакомство с JavaScript

Источник: https://learn.javascript.ru/

## Введение в JavaScript

JavaScript делали чтобы "оживлять" веб-страницы. Программы на нем называются скриптами, они подключаются к HTML и выполняются в браузере.

Сейчас JS работает не только в браузере, но и на сервере (Node.js), на мобильных устройствах (React Native) и т.д. Среда где выполняется код называется хост-средой.

Движки: V8 (Chrome, Node.js), SpiderMonkey (Firefox), JavaScriptCore (Safari).

Что умеет JS в браузере:

- менять содержимое и стили страницы
- реагировать на действия пользователя (клики, нажатия клавиш)
- отправлять запросы на сервер
- запоминать данные (cookie, localStorage)

Чего не может (из-за безопасности):

- нет доступа к файлам и системным функциям ОС
- камера и микрофон только с разрешения пользователя
- страницы с разных сайтов не могут свободно обмениваться данными

Есть языки которые превращаются в JS: TypeScript (добавляет типы), Dart, CoffeeScript.

## Привет, мир!

Скрипт вставляется тегом `<script>`:

```html
<!DOCTYPE html>
<html>
<body>
  <p>Перед скриптом...</p>

  <script>
    alert('Привет, мир!');
  </script>

  <p>...После скрипта.</p>
</body>
</html>
```

Внешний скрипт подключается через src:

```html
<script src="/path/to/script.js"></script>
```

Если указан src, то код внутри тега игнорируется. Внешние файлы удобнее: браузер их кеширует и код не дублируется на разных страницах.

## Структура кода

Код состоит из инструкций, они разделяются точкой с запятой.

```js
alert('Привет');
alert('Мир');
```

Точку с запятой можно не ставить если инструкции на разных строках (автоматическая вставка), но иногда это ломается, поэтому лучше ставить всегда.

Комментарии:

```js
// однострочный

/* многострочный
   комментарий */
```

Вложенные многострочные комментарии не работают.

## Строгий режим - "use strict"

Раньше в JS были странности, которые оставили для совместимости. В ES5 появились новые возможности, которые меняют старое поведение. Чтобы их включить, пишем в самом начале скрипта:

```js
"use strict";
```

- директива должна быть в самом начале (до нее только комментарии)
- отменить строгий режим нельзя
- классы и модули включают его автоматически
- в строгом режиме например нельзя использовать необъявленную переменную
- в консоли браузера он по умолчанию выключен

## Переменные

Переменная - это именованное хранилище для данных.

```js
let message;
message = 'Привет';
alert(message);

let user = 'Иван';
let age = 25;
```

Способы объявления:

- `let` - современный, значение можно менять
- `const` - константа, значение менять нельзя
- `var` - старый способ, лучше не использовать

Правила для имен:

- буквы, цифры, `$` и `_`
- первый символ не цифра
- регистр важен (apple и APPLE разные переменные)
- нельзя использовать зарезервированные слова (let, class, return и т.д.)

Имена должны быть понятными (userName, а не x), пишем в camelCase. Константы, которые известны заранее, пишем большими буквами:

```js
const COLOR_RED = "#F00";
```

Объявить одну переменную через let два раза нельзя, будет ошибка.

## Типы данных

JS язык с динамической типизацией: тип есть у значения, а не у переменной. Всего 8 типов, 7 примитивных и object.

- number - числа (целые и дробные)
- bigint - большие целые числа, `123n`
- string - строки
- boolean - true и false
- null - "пусто"
- undefined - значение не присвоено
- symbol - уникальные идентификаторы
- object - сложные структуры

Особые значения number: `Infinity` (например `1 / 0`) и `NaN` (ошибка вычисления, например `"abc" / 2`).

Строки бывают в трех видах кавычек:

```js
let single = 'одинарные';
let double = "двойные";
let backticks = `обратные, в них можно вставлять выражения: ${1 + 2}`;
```

null - это явное "ничего", undefined - значение не было присвоено.

Оператор typeof возвращает тип в виде строки:

```js
typeof undefined // "undefined"
typeof 0         // "number"
typeof 10n       // "bigint"
typeof true      // "boolean"
typeof "foo"     // "string"
typeof Symbol("id") // "symbol"
typeof Math      // "object"
typeof null      // "object" (это ошибка в языке)
typeof alert     // "function"
```

## Взаимодействие: alert, prompt, confirm

Три функции для общения с пользователем в браузере. Они останавливают выполнение кода пока окно не закрыто.

alert - показывает сообщение:

```js
alert("Привет");
```

prompt - запрашивает текст у пользователя:

```js
let result = prompt(title, [default]);
```

Возвращает введенную строку, а если нажали "Отмена" - null.

confirm - задает вопрос с кнопками OK и Отмена:

```js
let isBoss = confirm("Вы начальник?");
alert(isBoss); // true если OK, иначе false
```

Внешний вид этих окон менять нельзя, его определяет браузер.

# Основы JavaScript

## Преобразование типов

Операторы и функции сами приводят значения к нужному типу.

Строковое - `String(value)`:

```js
String(true);  // "true"
String(null);  // "null"
```

Численное - `Number(value)` или автоматически в математических выражениях:

```js
alert("6" / "2");   // 3
Number("  123  ");  // 123
Number("123z");     // NaN
Number(true);       // 1
Number(false);      // 0
Number(undefined);  // NaN
Number(null);       // 0
```

Логическое - `Boolean(value)`. Ложными становятся `0`, `""`, `null`, `undefined`, `NaN`, всё остальное true.

```js
Boolean(1);        // true
Boolean("привет"); // true
Boolean("0");      // true (строка не пустая)
Boolean(" ");      // true (пробел это тоже символ)
```

## Базовые операторы, математика

Операнд - то к чему применяется оператор. Унарный оператор - с одним операндом, бинарный - с двумя.

Математика: `+ - * / % **` (% - остаток от деления, ** - степень).

```js
alert(5 % 2);  // 1
alert(2 ** 3); // 8
```

Если хотя бы один операнд строка, то `+` склеивает строки:

```js
alert('1' + 2);     // "12"
alert(2 + 2 + '1'); // "41"
alert('1' + 2 + 2); // "122"
```

Остальные операторы переводят всё в числа: `6 - '2'` будет 4.

Унарный плюс превращает значение в число:

```js
alert(+"5");   // 5
alert(+true);  // 1
alert(+"");    // 0
```

Приоритет: унарные операторы, потом `**`, потом `* / %`, потом `+ -`, в конце `=`. Скобки меняют порядок.

Присваивание тоже оператор и возвращает значение, поэтому можно так: `a = b = c = 2 + 2`. Есть сокращенные формы: `+=`, `-=`, `*=`, `/=`, `%=`, `**=`.

Инкремент и декремент:

```js
let counter = 2;
counter++; // 3
counter--; // 2

let a = 1;
alert(++a); // 2 (сначала увеличивает, потом возвращает)
alert(a++); // 2 (возвращает старое значение, потом увеличивает)
```

Еще есть побитовые операторы (`& | ^ ~ << >> >>>`), они редко нужны. Оператор запятая вычисляет несколько выражений и возвращает последнее.

## Операторы сравнения

`> < >= <= == != === !==`, результат всегда boolean.

Строки сравниваются посимвольно по кодам Unicode:

```js
alert('Я' > 'А');         // true
alert('Кот' > 'Код');     // true
alert('Привет' > 'Прив'); // true (длиннее значит больше)
```

Если типы разные, значения приводятся к числам:

```js
alert('2' > 1);   // true
alert('01' == 1); // true
alert(true == 1); // true
```

Строгое равенство `===` сравнивает без приведения типов:

```js
alert(0 == false);  // true
alert(0 === false); // false
alert('' == false); // true
```

Лучше использовать `===` и `!==`, чтобы не было сюрпризов.

null и undefined:

- `null === undefined` - false
- `null == undefined` - true (они равны только друг другу)
- при сравнениях `< >` null становится 0, а undefined становится NaN

```js
alert(null > 0);       // false
alert(null == 0);      // false
alert(null >= 0);      // true (странность)
alert(undefined > 0);  // false
alert(undefined == 0); // false
```

Поэтому с null и undefined нужно быть осторожным, лучше сравнивать через `===`.

## Условное ветвление: if, '?'

if выполняет блок если условие истинно (оно приводится к boolean):

```js
let year = prompt('В каком году появилась спецификация ECMAScript-2015?', '');

if (year == 2015) {
  alert('Вы правы!');
} else if (year < 2015) {
  alert('Подумайте ещё...');
} else {
  alert('Слишком большое значение!');
}
```

else и else if не обязательны. Фигурные скобки лучше писать всегда.

Тернарный оператор `?` - короткая запись выбора из двух значений:

```js
let result = condition ? value1 : value2;

let accessAllowed = age > 18 ? true : false;
// то же самое что let accessAllowed = age > 18;
```

Можно делать цепочки, но так хуже читается:

```js
let message = age < 3 ? 'Здравствуй, малыш!' :
  age < 18 ? 'Привет!' :
  age < 100 ? 'Здравствуйте!' :
  'Какой необычный возраст!';
```

`?` не стоит использовать вместо if, когда надо просто выполнить действия, он нужен чтобы выбрать значение.

## Логические операторы

Три оператора: `||` (ИЛИ), `&&` (И), `!` (НЕ).

`||` возвращает первое истинное значение (или последнее, если истинных нет):

```js
alert(1 || 0);                 // 1
alert(null || 1);              // 1
alert(null || 0 || 1);         // 1
alert(undefined || null || 0); // 0
```

Можно использовать для значения по умолчанию:

```js
let name = userName || 'Аноним';
```

Вычисление ленивое: как только нашли истинное значение, остальное не вычисляется.

`&&` возвращает первое ложное значение (или последнее, если все истинные):

```js
alert(1 && 0);    // 0
alert(1 && 5);    // 5
alert(null && 5); // null
```

Приоритет у `&&` выше чем у `||`.

`!` приводит к boolean и инвертирует:

```js
alert(!true);     // false
alert(!!"текст"); // true (двойное НЕ приводит к boolean)
```

Приоритет у `!` самый высокий из трех.

## Операторы нулевого слияния и присваивания: '??', '??='

`??` возвращает первый операнд который не null и не undefined:

```js
let result = a ?? b;
// то же что (a !== null && a !== undefined) ? a : b
```

```js
let user;
alert(user ?? "Аноним"); // Аноним

let user2 = "Иван";
alert(user2 ?? "Аноним"); // Иван
```

Отличие от `||`: `||` считает ложными и 0, и пустую строку, и false, а `??` реагирует только на null и undefined:

```js
let height = 0;
alert(height || 100); // 100
alert(height ?? 100); // 0
```

`??` нельзя использовать вместе с `||` и `&&` без скобок, будет синтаксическая ошибка:

```js
let x = (1 && 2) ?? 3;
```

`??=` присваивает значение только если переменная null или undefined:

```js
let user = { name: null };
user.name ??= "Аноним";
alert(user.name); // "Аноним"
```

Похожие операторы: `||=` и `&&=`.

# Основы JavaScript 2

## Циклы while и for

Цикл повторяет код несколько раз.

while - выполняется пока условие истинно:

```js
let i = 0;
while (i < 3) {
  alert(i);
  i++;
}
```

do..while - сначала выполняет тело, потом проверяет условие (минимум один раз выполнится):

```js
let i = 0;
do {
  alert(i);
  i++;
} while (i < 3);
```

for - самый частый цикл:

```js
for (начало; условие; шаг) {
  // тело
}

for (let i = 0; i < 3; i++) {
  alert(i); // 0, 1, 2
}
```

Порядок: начало (один раз), проверка условия, тело, шаг, снова проверка условия. Любую часть можно пропустить, `for (;;)` - бесконечный цикл. Переменная из `for (let i ...)` видна только внутри цикла.

break - выходит из цикла:

```js
let sum = 0;
while (true) {
  let value = +prompt("Введите число", '');
  if (!value) break;
  sum += value;
}
```

continue - пропускает текущую итерацию и идет к следующей:

```js
for (let i = 0; i < 10; i++) {
  if (i % 2 == 0) continue;
  alert(i); // 1, 3, 5, 7, 9
}
```

break и continue нельзя использовать справа от `?`.

Метки нужны чтобы выйти сразу из нескольких вложенных циклов:

```js
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    let input = prompt(`Значение на координатах (${i},${j})`, '');
    if (!input) break outer;
  }
}
```

## Конструкция "switch"

switch заменяет несколько if, когда одно значение сравниваем с разными вариантами:

```js
let a = 2 + 2;

switch (a) {
  case 3:
    alert('Маловато');
    break;
  case 4:
    alert('В точку!');
    break;
  case 5:
    alert('Перебор');
    break;
  default:
    alert("Нет таких значений");
}
```

- значение сравнивается с case строго (`===`)
- при совпадении выполняется код до ближайшего break
- если break нет, выполнение проваливается в следующие case
- default не обязателен, выполняется если совпадений нет
- несколько case можно группировать:

```js
case 3:
case 5:
  alert('Это 3 или 5');
  break;
```

## Функции

Функции позволяют вызывать один и тот же код много раз.

```js
function showMessage() {
  alert('Всем привет!');
}

showMessage();
```

Переменные внутри функции локальные, снаружи их не видно. Внешние переменные функция видит и может менять.

```js
let userName = 'Иван';

function showMessage() {
  let message = 'Привет, ' + userName;
  alert(message);
}
```

Параметры:

```js
function showMessage(from, text) {
  alert(from + ': ' + text);
}

showMessage('Аня', 'Привет!');
```

Значения по умолчанию:

```js
function showMessage(from, text = "текст не добавлен") {
  alert(from + ": " + text);
}
```

Возврат значения через return:

```js
function sum(a, b) {
  return a + b;
}

let result = sum(1, 2);
alert(result); // 3
```

- если return без значения или его нет, функция возвращает undefined
- после return функция заканчивается
- нельзя делать перенос строки между return и значением

Названия функций должны описывать действие, обычно начинаются с глагола: show... (показать), get... (получить), calc... (вычислить), create... (создать), check... (проверить). Одна функция - одно действие.

## Function Expression

Функция в JS это значение, ее можно записать в переменную:

```js
let sayHi = function() {
  alert("Привет");
};

sayHi();
```

Это называется Function Expression. Функцию можно скопировать в другую переменную:

```js
let func = sayHi;
func();
```

Колбэки - функции которые передаются в другие функции, чтобы вызвать их позже:

```js
function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

ask(
  "Вы согласны?",
  function() { alert("Вы согласились."); },
  function() { alert("Вы отменили выполнение."); }
);
```

Разница между Function Declaration и Function Expression:

- Declaration (`function sum(a, b) {...}`) создается заранее, до выполнения кода, поэтому ее можно вызвать выше по тексту
- Expression (`let sum = function(a, b) {...};`) создается когда выполнение доходит до этой строки

Если нет причин использовать Expression, лучше использовать Declaration, она читается проще и доступна раньше.

## Стрелочные функции, основы

Короткий синтаксис для функций:

```js
let sum = (a, b) => a + b;
alert(sum(1, 2)); // 3
```

То же самое что:

```js
let sum = function(a, b) {
  return a + b;
};
```

Если один аргумент, скобки можно не писать. Если аргументов нет - пустые скобки:

```js
let double = n => n * 2;
let sayHi = () => alert("Привет!");
```

Если тело многострочное, нужны фигурные скобки и return:

```js
let sum = (a, b) => {
  let result = a + b;
  return result;
};
```

Удобно использовать в колбэках:

```js
ask(
  "Вы согласны?",
  () => alert("Вы согласились."),
  () => alert("Вы отменили выполнение.")
);
```

## Особенности JavaScript

Краткое повторение пройденного.

Код:

- инструкции разделяются `;` (лучше ставить всегда)
- блоки в `{...}`
- комментарии `//` и `/* */`
- строгий режим - `"use strict"`

Переменные и типы:

- `let`, `const`, `var` (старый)
- 8 типов: number, bigint, string, boolean, null, undefined, symbol, object
- тип узнаем через typeof

Взаимодействие с пользователем: prompt, confirm, alert.

Операторы:

- арифметические `+ - * / % **`, для строк `+` склеивает
- присваивание, инкремент и декремент
- сравнение: `==` нестрогое, `===` строгое
- логические `||`, `&&`, `!` и оператор `??`

Ветвление и циклы: if / else, тернарный оператор, while, do..while, for, break, continue, метки, switch.

Функции:

- Function Declaration: `function f(a, b) {...}`
- Function Expression: `let f = function(a, b) {...};`
- стрелочные: `let f = (a, b) => a + b;`
- у функций есть локальные переменные, параметры (в том числе со значениями по умолчанию) и return

Дальше в курсе: объекты, массивы, замыкания, асинхронность, DOM и события.
